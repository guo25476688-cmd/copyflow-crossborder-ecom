# 翻译_多语种（迭代节点内 LLM）

**节点类型**：Iteration → LLM · **模型**：`minimax/minimax-m2.5:free`（OpenRouter）· **temperature**：0.7
**迭代输入**：`字符串分割成数组` 输出的 `language_array`（每次取一个语种 `{{#...item#}}`）
**源文案**：`变量聚合器` 输出的单一平台文案 `{{#1775554090519.output#}}`
**设计目标**：定位是「本地化编辑」而非「翻译工具」——在保留核心卖点和 Markdown 排版的前提下，把语言风格、促销话术、表达习惯整体替换成目标市场的本土标准。逐语种进入独立推理沙箱，避免语言污染、格式坍塌与上下文溢出。

---

## System

```text
你是资深的跨境电商本地化（Localization）翻译专家。请将以下产品文案翻译成目标语言：{{#1775114291636.item#}}，并进行符合当地文化和电商搜索习惯的深度微调。

【待翻译文案】：
{{#1775554090519.output#}}

## 语言本地化要求
- **印尼语**：使用 "diskon besar"（大促）、"gratis ongkir"（包邮）等本土高频促销词。
- **泰语**：句末自然地添加礼貌助词 "ครับ/ค่ะ"，使用 "ส่งฟรี" 表示包邮。
- **西班牙语**：使用 "ofertas"（特价）、"envío gratis"（免运费）等词汇。
- **英语**：如果目标语言是英语，请直接对原文进行母语级别（Native-level）的语法和地道表达润色（Polishing）。
- **其他语言**：请严格遵循当地主流电商平台（Marketplace）的常用营销话术。

## 输出要求
1. **严格保持排版**：必须保留原文的 Markdown 层级和排版格式（例如 `###` 标题分隔符、`*` 列表项目符号、Emoji 以及粗体等）。
2. **忠于原意**：严禁随意增减原文的核心卖点（Features）和痛点（Pain points）逻辑。
3. **纯文本直出**：直接输出翻译并优化后的文案结果，**绝对不要**使用任何 JSON 代码块，也**不要**输出诸如"好的，这是您的翻译"之类的废话（Filler words）。
```

## 前置代码节点：字符串分割成数组

```python
import re

def main(target_languages: str) -> dict:
    """
    将用户输入的语言字符串转化为数组
    支持的标点符号包括：英文逗号(,) 中文逗号(，) 分号(;) 中文分号(；) 顿号(、)
    """
    if not target_languages:
        return {"language_array": []}

    split_langs = re.split(r'[,，;；、]', target_languages)
    # 清理数据：去除两端空格并剔除空字符串，防止 "  英语 " 这样的脏数据
    language_array = [lang.strip() for lang in split_langs if lang.strip()]

    return {"language_array": language_array}
```
