## 实验结论

1. **防编造校验有效**：所有成功出结果的评测中，编造率都是 0。这来自"依据必须是原文子串 + 数字必须与依据一致"的确定性校验，与思考开关无关。
2. **flash-v1 → v2 的大幅提升主要来自修复输出被截断**：deepseek-flash 默认开启思考，推理 token 占用输出上限（earbuds-01 的 2732 个输出 token 里有 1928 个是推理），2048 的上限会截断输出并导致空内容。
3. **关思考快约 4.5 倍、省约 4 倍 token，但缺失信息识别从约 90% 掉到 72%**：漏掉的是母婴的适用月龄、护肤的全成分与保质期等品类关键项。开着思考时模型会先判断品类再列必问项。
4. **p3 提示词修好了 yoga-mat 的"无毒无味"被当事实，但有副作用**：开思考时，卖家写明的具体规格（防摔 1.5 米、BPA free）也被当成"禁止声称"，召回从 100% 降到 96%。
5. **降低推理强度（low）收益不明显**：token 与耗时只小幅下降，缺失信息识别也没有更好，暂不采用。

## 方法论提醒

以上提示词调整都是看着这 10 个用例的失败去改的，**这 10 个用例已经被"用过"了**，在它们上面继续提升的数字会虚高。后续对提示词的进一步改动，需要用一批调提示词时没见过的留出用例来验证。
